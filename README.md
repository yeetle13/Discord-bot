# 🛠️ Discord Utility & Moderation Bot Template

A clean, lightweight, and easy-to-configure Discord moderation bot built with Node.js and `discord.js`. Perfect for community server owners looking for simple moderation tools.

## 🚀 Features & Commands
* `!clear <1-100>` — Bulk delete recent channel messages.
* `!kick @user [reason]` — Kick a disruptive member from the server.
* `!ban @user [reason]` — Ban a user from the server.
* `!help` — Displays the interactive command menu.
